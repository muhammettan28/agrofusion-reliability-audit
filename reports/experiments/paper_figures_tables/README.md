# Manuscript figures

This directory contains the compact figures used by the current class-wise
coverage and hierarchical backoff manuscript:

- `fig_coverage_gap.pdf`: aggregate and macro coverage gap.
- `fig_classwise_coverage_heatmap.pdf`: class-wise coverage heatmap.
- `fig_reliability_diagram.pdf`: supplementary reliability diagram.
- `fig_backoff_frontier.pdf`: supplementary backoff frontier.
