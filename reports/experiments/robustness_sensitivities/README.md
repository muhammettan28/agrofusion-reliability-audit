# Cached robustness sensitivity analyses

Run from the repository root with the existing NumPy/Polars analysis environment:

```bash
PYTHONPATH=src python -m agrofusion_reliability.evaluation.build_robustness_sensitivity_report
```

No models are fitted, no validation thresholds are reselected and no test labels
select an operating point. Existing actions and probability caches are read only.

The new-site temporal comparison excludes every point seen in the source year,
including validation-only points. Membership uses the hashed released index and
stable sample IDs across years; fine LC1 labels are truncated to family codes as
in the original fit. Counts and macro denominators are retained per direction.
Exact revisits are excluded; broader spatial dependence can remain.

AUGRC integrates accepted-error mass over total evaluation support against
coverage, with trapezoidal interpolation of whole score-tie blocks. This agrees
with the failure-AUROC identity including half weight for tied pairs. CA-AUGRC
averages independently integrated within-true-family areas, weighting each
observed class equally. Existing right-constant AURC/CA-AURC values are recomputed
and checked against the stored summaries before any new output is written.

`specificity_checks.csv` compares entropy, family-output rate, linear-depth
weights (family 1, major 0.5, abstention 0), and accepted normalized tree distance
for five specified normal seed-42 policies. Matching their orders does not
establish robustness to arbitrary semantic costs.

`manifest.json` records all input hashes. Manuscript tables are generated by
`reports/experiments/focused_policy_comparison/build_support_tables.py`.
